📮 預けた手紙

📥 アメブロの記録を取り込む

若い頃に書いたアメーバブログ「数楽者のボヤキ・ツブヤキ・ササヤキ」の記事 件分が、このファイルに埋め込まれています。押すだけで取り込めます（同じ記事は二重に取り込みません）。

📝 noteへ取り込む（MT形式で書き出し）

記録を note のインポート形式（MT形式）で書き出します。noteでは下書きとして取り込まれ、元の日付が保持されます。本文が空のアメブロ記録は「タイトル＋元記事へのリンク」が本文になります。

手順：①このボタンで .txt ファイルを保存 → ②noteにログインし「インポート」を開く → ③MT形式のファイルを選んで取り込む。詳しくは README をご覧ください。

💾 バックアップと移行

データはこの端末のブラウザ内（localStorage）にだけ保存されます。機種変更やブラウザのデータ消去に備えて、ときどき書き出しておいてください。Muse版との移行も、この書き出し／読み込みでできます。

CSVの形式：1行目は見出し（date,title,body,url）、日付は YYYY-MM-DD で書いてください。

⚠️ データの削除

この端末に保存された記録・手紙・ひとことをすべて消します。取り消せませんので、必要な場合は先に書き出してください。
