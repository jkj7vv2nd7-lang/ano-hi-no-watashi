# あの日の私（単体HTML版）

過去の自分と再会するための、小さな日記の本棚アプリです。
このフォルダの `index.html` 1ファイルだけで動きます。

## 使い方（GitHub PagesでURLから使う）

1. GitHubに新しいリポジトリを作ります（例：`ano-hi-no-watashi`）。
2. このフォルダの `index.html`、`README.md`、`icon.png` をアップロードします。
3. リポジトリの Settings → Pages で、公開するブランチ（main）を選びます。
4. 数分待つとURLが発行されます。そのURLをiPhoneのSafariで開き、「ホーム画面に追加」しておくと便利です。
   - `icon.png` はこのアプリのアイコン（開いた日記帳と封をした手紙の絵）です。「ホーム画面に追加」をすると、このアイコンがホーム画面に並びます。

## データの保存について

- データは**その端末・そのブラウザの中（localStorage）にだけ**保存されます。サーバーには送られません。
- Muse版『あの日の私』とはデータは共有されません。移したいときは、片方で「JSONで書き出す（全データ）」をして、もう片方で「JSON／CSVを読み込む」から読み込んでください。
- 機種変更やブラウザのデータを消すと記録も消えてしまいます。ときどきJSON書き出しでバックアップを取ってください。

## 主な機能

- **ホーム「今日の再会」**：同じ月日の過去の記録があれば「○年前の今日」として表示。なければ思い出の中から1件を表示します。
- **今日のひとこと**：その日の気持ちをひとこと保存。来年の今日に再会できます。「🎤 声で書く」はブラウザの音声認識（Web Speech API）を使い、ボタンを押したときだけ動作します（ブラウザによっては音声が提供事業者のサーバーで処理される場合があります）。
- **記録**：追加・一覧・検索・年フィルター・編集・削除（削除は確認つき）。
- **未来への手紙**：半年後／1年後／3年後／任意の日を指定して封印。届く日までは本文を開けません。届くとホームに表示されます。
- **年表**：年ごとの件数から、その年の記録に絞り込めます。
- **アメブロ取り込み**：アメーバブログ「数楽者のボヤキ・ツブヤキ・ササヤキ」の記事1,826件（2005年3月6日〜2011年7月28日）が埋め込まれていて、ワンタップで取り込めます。同じ記事（URL）は二重に取り込みません。本文は持たず、元記事へのリンクから読む形です。
- **読み込み**：JSON（このアプリ／Muse版の書き出しファイル）／CSV（見出し date,title,body,url、日付は YYYY-MM-DD）。

## noteへの取り込み方

記録を note に下書きとして取り込み、元の日付も残せます。

1. アプリの「データ」画面にある **「全件を書き出す」**（または「表示中の記録を書き出す」）を押して、`.txt` ファイル（MT形式）を保存します。
   - 「表示中の記録」は、「記録」画面の年フィルターと検索に合う記録だけが対象です。特定の年だけを移したいときに便利です。
   - 本文が空のアメブロ記録は、「タイトル＋元記事へのリンク」が本文になります。
2. noteにログインし、**「インポート」** の画面を開きます。
3. **MT形式のファイル**として、保存した `.txt` ファイルを選んで取り込みます。
4. 取り込まれた記事は**下書き**として入り、**日付は元の記録の日付**になります。内容を確認してから公開してください。

※ noteへの取り込みは、note側の仕様変更などで手順が変わる場合があります。
※ 書き出したMTファイルには記録のタイトルと本文が含まれます。人に見せたくない内容が含まれる場合は、取り込み後に下書きのまま確認してください。

## 動作環境

- モダンなブラウザ（iPhoneのSafari、Chrome等）で動作します。
- 音声入力はブラウザの対応状況に依存します（iPhoneのSafariでは概ね端末内で処理されます）。
